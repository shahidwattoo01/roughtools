## How PDF Compression Works

Every PDF is made of four components that compress at different rates:

| Component | Share of File Size | Compression Possible |
|---|---|---|
| Embedded images | 60–90% | **40–85% reduction** |
| Embedded fonts | 5–20% | 10–40% reduction |
| Vector graphics | 2–10% | Minimal — already efficient |
| Text content | 1–5% | 30–60% via deflate |

**Two types of compression:**

- **Lossless** — applied to text and vector graphics. Zero quality loss. Every character stays pixel-perfect and fully searchable.
- **Lossy** — applied to images. Reduces DPI. At Screen quality, the visual difference vs. the original is invisible on any monitor or phone.

**The three compression levels:**

| Level | Image DPI | Best For | File Size |
|---|---|---|---|
| Screen | 72–96 DPI | Email, portals, WhatsApp, job apps | Smallest |
| Ebook | 150 DPI | Thesis, archiving, sharing | Balanced |
| Print | 300 DPI | Print shop submissions | Minimal reduction |

For 95% of everyday use — email, website uploads, university portals, job applications — **Screen quality** is always the right choice.

## Why Is My PDF So Large?

**The 5 main causes:**

**1. High resolution embedded images** — Word and PowerPoint embed images at 300 DPI by default. A single high resolution photo weighs 3–8 MB. At 96 DPI it weighs 200–500 KB with no visible screen difference. **Compression headroom: 70–90%.**

**2. Full embedded font sets** — Every typeface adds 200–500 KB. A PDF using 5 fonts carries 1–2.5 MB in font data alone. **Compression headroom: 10–40%.**

**3. Duplicated embedded content** — A logo on 40 slides may be stored 40 separate times. PDF optimizers detect and remove duplicates. **Compression headroom: 10–50% for affected files.**

**4. Uncompressed scanned pages** — Raw images inside a scanned PDF inflate size dramatically. **Compression headroom: 40–75%.**

**5. Hidden metadata and layers** — Design-tool PDFs carry editing history, hidden layers, and revision data invisible in the final document. Flattening removes this overhead. **Compression headroom: 5–20%.**

## Common Mistakes When Compressing PDFs

**Re-compressing at the same level.**
Near-zero reduction and cumulative image quality loss. If you need further reduction, use a *lower* quality setting — not the same one twice.

**Using print quality for email or portals.**
Print compression (300 DPI) barely reduces file size. Always use Screen or Ebook for email, WhatsApp, and online submissions.

**Compressing a scanned PDF before OCR.**
If you need searchable text, run OCR first, then compress.

**Not checking the compressed file before sending.**
Compression can occasionally break hyperlinks or corrupt pages. Open, scroll through, and click links before attaching to any email or submitting to any portal.
