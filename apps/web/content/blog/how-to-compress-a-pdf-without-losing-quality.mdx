## How PDF Compression Works

Understanding compression makes results predictable. Every PDF file is made of four components that compress at different rates:

| Component | Share of File Size | Compression Possible |
|---|---|---|
| Embedded images | 60–90% | **40–85% reduction** |
| Embedded fonts | 5–20% | 10–40% reduction |
| Vector graphics | 2–10% | Minimal — already efficient |
| Text content | 1–5% | 30–60% via deflate |

**Two types of compression:**

- **Lossless compression** — applied to text and vector graphics. Zero quality reduction. Every character remains pixel-perfect.
- **Lossy compression** — applied to images. Reduces resolution (DPI). The degree of visible change depends on compression level: screen quality (72–96 DPI) looks identical to 300 DPI print quality on any monitor.

**The three compression levels:**

| Level | Image DPI | Best For | File Size |
|---|---|---|---|
| Screen | 72–96 DPI | Email, web upload, portals | Smallest |
| Ebook | 150 DPI | Most documents, archiving | Balanced |
| Print | 300 DPI | Documents being physically printed | Largest |

For 99% of use cases — email, website upload, job applications, government forms — **Screen quality** is the right choice. The visual result is identical to the original on any screen.

## Why Is My PDF So Large?

Five reasons PDFs balloon in size — and how much compression each allows:

**1. High-resolution embedded images** — The #1 cause. Word, PowerPoint, and design tools embed images at 300 DPI (print quality) by default. A full-page photo at 300 DPI weighs 3–8 MB. Compressing to 96 DPI reduces it to 200–500 KB with no visible change on screen. **Compression headroom: 70–90%.**

**2. Full embedded font sets** — Professional PDFs embed entire font files to ensure text renders correctly on every device. A single font file adds 200–500 KB. Documents using 5–6 fonts accumulate 2–3 MB in font data alone. **Compression headroom: 10–40%.**

**3. Duplicate embedded content** — A logo pasted on 40 slides may be stored 40 times instead of once. PDF optimization deduplicates this. **Compression headroom: 10–50% for affected files.**

**4. Unoptimized scanned pages** — Scanned PDFs store each page as a raw image (often TIFF or uncompressed BMP). A 10-page scan at 300 DPI with no compression can exceed 50 MB. **Compression headroom: 40–75%.**

**5. Hidden metadata and revision history** — Design-tool PDFs carry layers, hidden objects, and editing history invisible in the final document. Flattening and compressing removes this overhead. **Compression headroom: 5–20%.**

## Common Mistakes When Compressing PDFs

**Compressing an already-compressed PDF at the same level.**
Re-running the same compression produces almost no size reduction and degrades image quality. If you need further reduction, use a *lower* quality setting — not the same one twice.

**Using print-quality settings for email.**
Print compression (300 DPI) barely reduces file size. For email and online use, always pick Screen or Ebook. Most people never change the default — the default is usually Print.

**Compressing a scanned PDF before OCR.**
If you need searchable text, run OCR first, then compress.

**Uploading sensitive documents to unknown tools.**
Many free PDF tools store uploaded files indefinitely. RoughTools processes files in memory and deletes them immediately after download. For confidential documents, always verify the privacy policy of any tool you use.

**Not checking the compressed file before sending.**
Rare but real: compression can occasionally break hyperlinks or corrupt pages. Open, scroll, and click links before attaching to an email.

## How to Make PDF Smaller Without Losing Quality — Key Tips

- **Remove unnecessary pages first.** Use [Split PDF](/tools/pdf/split-pdf) to delete blank pages, cover pages you don't need, or appendices before compressing.
- **Flatten before compressing.** PDFs with transparent layers or annotations carry hidden overhead. Printing to PDF first removes this.
- **Export from source at lower DPI.** If you created the PDF from Word or PowerPoint, re-export with 150 PPI image settings for a smaller starting file.
- **Don't compress twice at the same level.** Each repeated pass at the same quality yields diminishing returns and accumulates quality loss on images.
- **Use splitting for very large files.** A 100-page PDF that must be under 1 MB cannot be achieved through compression alone. Split into sections.
